## Ships

A stranger can sign up at a public URL, pick a handle, and post within today's number,
a limit between 1 and 42 that changes every day, and read everyone's posts on one
global timeline.

## Done when

- [ ] Today's number is shown on the timeline and drives the composer
- [ ] A post one character over today's number is rejected by the server, not just the composer
- [ ] CI runs unit and end-to-end tests on every PR and they pass
- [ ] README lets a stranger run it locally

## Explicitly not in this milestone

- Following, replies, likes, reposts, the reply funnel, day pages: v0.2
- Deleting posts, profile pages: v0.2
- Rate limits and moderation: v0.3
