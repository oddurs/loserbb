# Security Policy

## Supported versions

loserbb has no releases yet. Until 1.0, only the latest commit on `main` receives fixes.

## Reporting a vulnerability

Report privately through
[GitHub Security Advisories](https://github.com/oddurs/loserbb/security/advisories/new).
Do not open a public issue.

loserbb stores accounts, passwords, and sessions, and renders text from strangers, so
reports about account takeover, session handling, or script injection through posts are
especially welcome.

## What to expect

- Acknowledgement within 3 days.
- An assessment and a planned fix date within 14 days.
- Credit in the advisory and changelog, unless you prefer otherwise.
